Titanic Data Visualization 

Project Overview

This project focuses on exploring and visualizing the Titanic passenger dataset using Python, Matplotlib, and Seaborn. It presents meaningful patterns and relationships through different visualizations to better understand passenger demographics, fares, and survival rates.

Objectives

- Understand the distribution of passenger ages.
- Identify potential outliers.
- Compare survival rates by gender.
- Explore the relationship between age and ticket fare.
- Analyze correlations between numerical features.

Dataset

Titanic Dataset – Contains passenger information such as:

- PassengerId
- Survived
- Pclass
- Name
- Sex
- Age
- SibSp
- Parch
- Ticket
- Fare
- Cabin
- Embarked

Technologies & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

Visualizations

1. Histogram: Displays the age distribution of Titanic passengers.
2. Box Plot: Identifies potential outliers in passenger ages.
3. Bar Chart: Compares survival rates between male and female passengers.
4. Scatter Plot: Explores the relationship between passenger age and fare.
5. Correlation Heatmap: Shows correlations between numerical dataset features.

Key Insights

- Female passengers had a higher survival rate than male passengers.
- First-class passengers had a higher survival rate than third-class passengers.
- Age distribution and potential outliers can be explored using a histogram and box plot.
- The scatter plot helps examine the relationship between age and fare.
- The correlation heatmap highlights relationships between numerical features.

Project Deliverables

- Titanic Dataset (".csv")
- Five saved visualization images (".png")
